# Amazon Homepage Clone

## Project Overview
This is a static clone of the Amazon homepage built using HTML and CSS.

## Features
- Navigation Bar with Search
- Hero Section with Background Image
- Product Cards Grid Layout
- Seller Section
- Multi-column Footer
- Hover Effects

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Font Awesome

## Project Purpose
This project was created to practice front-end development skills and improve UI layout designing using CSS Flexbox.
